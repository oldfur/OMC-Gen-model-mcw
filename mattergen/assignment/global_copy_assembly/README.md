# Global Structured Copy Assembly MVP

This is a standalone clean-geometry, oracle-role diagnostic.  It does not
implement assignment diffusion, masked-Q repair, noisy geometry, iterative
refinement, a joint sampler, or pos/cell denoiser integration.

## Convention and target isolation

For the stable crystal-index-sorted instances
`V_r=(v[r,0],...,v[r,K-1])`, the only convention is

\[
P_r[q]=k,
\]

meaning instance `q` of role `r` has unified copy-gauge label `k`.  The anchor
role must be in a singleton molecular-automorphism orbit.  Its stable atom
order fixes gauge, so `P_anchor[q]=q`.  `mol_copy_id` is used only by
`targets.build_assembly_target` to form supervised `P*`; no predictor API
accepts it, `C0`, or `Q0`.

## Model

The standalone periodic crystal encoder consumes clean `(X0,L0,z)` and the
molecular encoder consumes element/bond graph information.  For a molecular
edge `(r,s,b)`, `BondPairPotential` produces a K-by-K scalar matrix
`w_rs(q,q')`.  It contains crystal pair embeddings, molecular role embeddings,
bond type and minimum-image PBC-distance RBFs, but no copy information.

For each deterministic BFS spanning-tree edge and permutation states `u,v`:

\[
\Phi_{rs}(u,v)=\sum_q w_{rs}(q,v^{-1}(u(q))).
\]

The inverse table is precomputed once for all `K!` states.  Non-tree graph
edges are recorded by `tree_builder` but are not used by this MVP CRF.

Unlike independent anchor-star masked Q, all role permutations are variables
of one CRF and every tree factor is scored jointly during one exact MAP or
sum-product pass.  The anchor fixes only copy-label gauge; it does not turn
each non-anchor role into an independent prediction problem.

`TreeCRF` performs tensorized exact sum-product with `torch.logsumexp`:

\[
m_{c\to p}(u)=\log\sum_v\exp[\Phi_{pc}(u,v)+\sum_gm_{g\to c}(v)].
\]

The root is forced to identity.  The structured loss is
`(logZ - S(P*)) / number_of_tree_edges` plus optional bidirectional pair CE.
`map_decode` uses exact max-product and stored backpointers; it never performs
independent per-role Hungarian matching.

## Decoding and scope

The decoded permutations form `G[N,K]`, then `C=G G^T`; every atom has one
group and every group has exactly M atoms.  Future evaluation must report
`CLEAN_GEOMETRY_ORACLE_R_ONLY`, C/pair metrics, projected molecular graph and
cross-copy false molecular edges.  Literal role exactness is not a primary
metric because each copy may independently use a molecular automorphism.

This package only asks whether global semantic copy assembly can be learned
from clean geometry plus oracle R.  It cannot establish noisy-geometry
stability or any improvement of pos/cell reverse denoising.

## Future-only output contract

When a later explicitly authorized run occurs, the configured output directory
will contain `config_audit.json`, `anchor_and_tree.json`,
`permutation_convention.json`, `training_trace.jsonl`,
`checkpoint_selection.json`, `evaluation_metrics.json`,
`condition_ablation.json`, `per_sample_metrics.jsonl`, and
`global_copy_assembly_report.md`.  No such metrics are generated by this
implementation-only change.

## Geometry-only predicted-R extension

The implementation now also supports a standalone predicted-R role source
selected via `global_copy_assembly.role_source: geometry_only_hard_r` and
`global_copy_assembly.mode: clean_geometry_predicted_r`.  This path uses a
hard geometry-only role artifact as the only role source and keeps
`mol_copy_id`, `C0`, and oracle copy relations out of the encoder/pair
potential/tree-CRF forward.
